Verge Explorer API

Public base URL: https://mempool.vergecurrency.com. These are read-only mainnet endpoints. No API key is required.

Very large address and history queries can be slow or time out. Full-range amount handling and sustained load remain under qualification. Verify critical balances independently.

Chain and transactions

GET routeReturns
/api/v1/chainChain, network, genesis and amount units as JSON
/api/blocks/tip/heightIndexed tip height as text
/api/blocks/tip/hashIndexed tip hash as text
/api/block-height/{height}Canonical block hash at a height as text
/api/block/{hash}Block details as JSON
/api/tx/{txid}Transaction details as JSON
/api/tx/{txid}/hexRaw transaction hex as text

Addresses and history

Large histories may exceed the public timeout.

GET routeReturns
/api/address/{address}Confirmed and mempool statistics as JSON
/api/address/{address}/txsTransaction history page as JSON
/api/address/{address}/utxoUnspent outputs as JSON

Live updates

Connect a WebSocket client to wss://mempool.vergecurrency.com/api/v1/ws, then send:

{"action":"want","data":["blocks","stats","mempool-blocks"]}
{"action":"init"}

The initial response includes chain identity and recent blocks. New block messages follow as the indexer catches up.

Example

curl -fsS https://mempool.vergecurrency.com/api/blocks/tip/height
curl -fsS https://mempool.vergecurrency.com/api/v1/chain

Transaction submission is disabled on this public gateway. Explorer source on GitHub.
